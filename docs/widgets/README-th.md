# Quick Wallet: วิดเจ็ตหน้าจอโฮมและทางลัด (iPhone + Android)

คู่มือนี้อธิบายวิธีแสดงยอดเงินบนหน้าจอโฮม/หน้าจอล็อก และเพิ่มรายจ่าย รายรับ หรือการโอนได้เร็ว ๆ จากโทรศัพท์ โดยใช้ **โทเคน** ที่คุณสร้างและจัดการเองในแอป

> ทุกอย่างที่ต้องคัดลอก (ที่อยู่ URL, สูตร, โทเคน, id ของกระเป๋า) อยู่ในแอปที่ **ตั้งค่า → วิดเจ็ตและทางลัด** พร้อมปุ่มคัดลอก คู่มือนี้คือคำอธิบายแบบละเอียดประกอบหน้านั้น

## 1. ข้อจำกัดของแต่ละระบบ (อ่านก่อน)

- **วิดเจ็ตพิมพ์ข้อมูลไม่ได้** ทั้งบน iOS และ Android การเพิ่มรายการด่วนจึงมี 2 แบบ
  - **(ก) ปุ่มบนวิดเจ็ตเปิดฟอร์มในแอป** (deep link) เช่น `https://แอปของคุณ/?quick=expense` แอปจะเปิดฟอร์มเพิ่มรายการ เลือกประเภทให้แล้ว
  - **(ข) ทางลัด (Shortcut)** ถามจำนวนเงิน เลือกกระเป๋า แล้วบันทึกตรงผ่านโทเคนแบบ **อ่าน + เขียน** โดยไม่ต้องเปิดแอป
- **วิดเจ็ตไม่อัปเดตแบบเรียลไทม์** ระบบปฏิบัติการเป็นผู้กำหนดรอบรีเฟรช ประมาณทุก 15–60 นาที (สคริปต์ iPhone ขอรอบละ 20 นาที แต่ iOS อาจเลื่อนออกไป)
- **iPhone: ลิงก์จากวิดเจ็ตเปิดใน Safari** ไม่ใช่แอปที่เพิ่มไว้บนหน้าจอโฮม (iOS ไม่มีวิธีให้ลิงก์เปิดเว็บแอปบนหน้าจอโฮม) เว็บแอปบนหน้าจอโฮมกับ Safari เก็บการเข้าสู่ระบบแยกกัน ดังนั้น **ครั้งแรกต้องเข้าสู่ระบบใน Safari หนึ่งครั้ง** หลังจากนั้นปุ่มจะเปิดฟอร์มใน Safari ได้ทันที ถ้าไม่อยากเปิด Safari ให้ใช้ทางลัด (ข้อ 5) และตั้งปุ่มวิดเจ็ตเป็น `buttons=shortcut`
- **Android: ลิงก์จะเปิดในแอปที่ติดตั้ง** ถ้าติดตั้งแอปจาก Chrome (เมนู ⋮ → ติดตั้งแอป) ระบบจะส่งลิงก์ของแอปไปเปิดในแอปที่ติดตั้งแทน Chrome ถ้าเคยเพิ่มไว้แบบ "เพิ่มลงในหน้าจอหลัก" แบบเก่า ให้ลบแล้วติดตั้งใหม่หนึ่งครั้ง
- **ยอดรวมกับหุ้น** วิดเจ็ตดึงราคาหุ้นสดไม่ได้ (ราคาสดดึงโดยแอปในเบราว์เซอร์ด้วยคีย์ของแอป) ถ้าคุณมีหุ้น ยอดรวมจะคิดหุ้นตาม **ต้นทุน** และมีป้าย **“รวม (ต้นทุนหุ้น)”** กำกับในทุกแบบที่แสดงยอดรวม ตัวเลขจึงอาจต่างจากหน้าหลักเท่ากับกำไร/ขาดทุนที่ยังไม่รับรู้ ถ้าไม่มีหุ้นถือ ตัวเลขจะตรงกับหน้าหลักทุกสตางค์
- **วันที่ของรายการ** ถ้าทางลัดไม่ส่ง `date` มา เซิร์ฟเวอร์ใช้ "วันนี้" ตามเขตเวลาของโปรเจกต์ Apps Script (ตั้งค่าโปรเจกต์ → เขตเวลา ควรเป็น `Asia/Bangkok`) ทางลัดในคู่มือนี้ส่งวันที่จากโทรศัพท์มาเอง จึงตรงกับเขตเวลาของคุณเสมอ วันที่ล่วงหน้าเกิน 1 วันจะถูกปฏิเสธ

## 2. ติดตั้งฝั่งเซิร์ฟเวอร์ (Code.gs)

ทำครั้งเดียว หลังจากได้ `Code.gs` เวอร์ชันใหม่

1. เปิด Google Sheet ของคุณ → **ส่วนขยาย → Apps Script**
2. เลือกไฟล์ `Code.gs` ลบของเดิมทั้งหมด วางเนื้อหาใหม่ทั้งไฟล์ แล้วกด **บันทึก**
3. **Deploy เป็นเวอร์ชันใหม่ โดยใช้ URL เดิม**
   - กด **ทำให้ใช้งานได้ (Deploy) → จัดการการทำให้ใช้งานได้ (Manage deployments)**
   - เลือกการ deploy ที่ใช้อยู่ → ไอคอนดินสอ (แก้ไข) → **เวอร์ชัน: เวอร์ชันใหม่ (New version)** → **ทำให้ใช้งานได้**
   - ห้ามกด "การทำให้ใช้งานได้รายการใหม่" (New deployment) เพราะจะได้ URL `/exec` ใหม่ แล้วแอปจะยังเรียก URL เก่า
4. ตรวจการตั้งค่าการเข้าถึงในหน้าเดียวกัน
   - **ดำเนินการในฐานะ (Execute as): ฉัน (Me)**
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)**
   - ต้องเป็น "ทุกคน" เท่านั้น ถ้าเป็น "ทุกคนที่มีบัญชี Google" หรือ "เฉพาะฉัน" วิดเจ็ตและทางลัดจะเรียกไม่ได้ เพราะโทรศัพท์ไม่ได้ลงชื่อเข้า Google ในคำขอ (ตัวแอปเองก็ใช้งานไม่ได้เช่นกัน) ข้อมูลยังปลอดภัย เพราะทุกคำขอต้องมีเซสชันที่ลงชื่อแล้วหรือโทเคนวิดเจ็ตที่ถูกต้อง
5. ในตัวแก้ไข เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้ (Run)** ถ้ามีรายงานว่าขาดคอลัมน์/ชีต ให้เรียก **`createMissingSheets`** หนึ่งครั้ง ระบบจะ
   - สร้างชีต **`ApiTokens`** (เก็บแค่ค่าแฮชของโทเคน ไม่ใช่ตัวโทเคน)
   - เพิ่มคอลัมน์ **`Source`** ต่อท้ายชีต `Transactions` ถัดจาก `Installment Index` (คือคอลัมน์ **M** ถ้าชีตมี 12 คอลัมน์ A–L ตามปกติ) รายการที่มาจากวิดเจ็ตจะมีค่า `widget:<ชื่อโทเคน>` รายการจากแอปเว้นว่าง
   - ถ้าลืมขั้นตอนนี้ ระบบจะเพิ่มหัวคอลัมน์ `Source` ให้เองตอนสร้างโทเคนและก่อนบันทึกรายการจากวิดเจ็ต แต่ควรรันไว้ก่อนอยู่ดี
   - ห้ามแทรกหรือย้ายคอลัมน์ในชีต `Transactions` เอง เพราะระบบเขียนข้อมูลตามตำแหน่งคอลัมน์
6. เรียก **`testWidgetTokens`** แล้วดู **บันทึกการดำเนินการ (Execution log)**
   - ฟังก์ชันจะใช้ผู้ใช้คนแรกและกระเป๋าใช้จ่ายใบแรก สร้างโทเคนทดสอบ อ่าน เขียน ลองเขียนด้วยโทเคนอ่านอย่างเดียว เพิกถอน แล้วลองอีกครั้ง
   - ทุกบรรทัดควรขึ้นต้นด้วย `PASS` และบรรทัดสุดท้ายเป็น `testWidgetTokens: all checks passed, test rows removed.`
   - รายการทดสอบ (฿1.23) และโทเคนทดสอบถูกลบออกเองเมื่อจบ แม้การทดสอบจะล้มเหลวกลางทาง
7. (แนะนำ) **ตั้งค่าโปรเจกต์ (Project Settings) → เขตเวลา** เป็น `(GMT+07:00) Bangkok`

## 3. โทเคน: สิทธิ์ การสร้าง เพิกถอน และสร้างใหม่

### สิทธิ์สองแบบ

| | อ่านอย่างเดียว | อ่าน + เขียน |
|---|---|---|
| ยอดรวม และยอดของกระเป๋าที่เลือก | ✅ | ✅ |
| ดูรายการ (transactions), โน้ต, ข้อมูลอื่น | ❌ | ❌ |
| เพิ่มรายจ่าย / รายรับ / การโอน | ❌ | ✅ เฉพาะกระเป๋าและประเภทที่อนุญาต |
| แก้ไข ลบ หรือจัดการโทเคน | ❌ | ❌ |

- สิทธิ์ของโทเคน **เปลี่ยนไม่ได้หลังสร้าง** ถ้าต้องการสิทธิ์อื่น ให้สร้างโทเคนใหม่
- ตัวเลือกอื่น ๆ ต่อโทเคน
  - **กระเป๋าที่แสดง** เลือกได้สูงสุด 12 ใบ เรียงลำดับได้ ถ้าเว้นว่างจะแสดงแค่ยอดรวม
  - **ยอดรวม** แบบ "เหมือนหน้าหลัก" (กระเป๋าทุกใบที่ไม่ได้เก็บเข้าคลัง) หรือ "เฉพาะกระเป๋าที่แสดง"
  - **ซ่อนจำนวนเงิน** เซิร์ฟเวอร์จะไม่ส่งตัวเลขมาเลย (ส่ง `•••` และ `null`) โทเคนนี้หลุดไปก็เห็นแค่ชื่อกระเป๋า
  - **วันหมดอายุ** ไม่หมดอายุ / 30 / 90 / 365 วัน
- ใช้งานพร้อมกันได้สูงสุด **10 โทเคน**

### สร้างโทเคน

1. แอป → **ตั้งค่า → วิดเจ็ตและทางลัด → เปิด** (หรือ เมนู "เพิ่มเติม" → วิดเจ็ตและทางลัด)
2. กด **โทเคนใหม่** ตั้งชื่อ (เช่น `iPhone`) เลือกสิทธิ์ กระเป๋า และตัวเลือก แล้วกด **สร้างโทเคน**
3. **โทเคนแสดงแค่ครั้งเดียว** กดคัดลอกแล้วเก็บไว้ในที่ปลอดภัย (เช่น แอปจัดการรหัสผ่าน) ด้านล่างจะมีขั้นตอนตั้งค่าของ iPhone/Android พร้อมค่าที่เติมไว้ให้แล้ว
4. ปิดหน้าต่างแล้วจะเห็นโทเคนแค่ส่วนต้น เช่น `qw_ab12…`

### เพิกถอน (Revoke)

กด **เพิกถอน** → ยืนยัน วิดเจ็ตและทางลัดทุกตัวที่ใช้โทเคนนี้หยุดทำงานทันที ย้อนกลับไม่ได้

### สร้างใหม่ (Regenerate)

ได้โทเคนใหม่ที่ตั้งค่าเหมือนเดิม โทเคนเก่าหยุดทำงานทันที ใช้เมื่อสงสัยว่าโทเคนหลุด หรือลืมโทเคน จากนั้นต้องใส่โทเคนใหม่ในทุกวิดเจ็ต/ทางลัดที่ใช้อยู่ โทเคนที่หมดอายุแล้วต้อง **แก้ไขวันหมดอายุ** ก่อนจึงจะสร้างใหม่ได้

### ความปลอดภัย

- โทเคนมีรูปแบบ `qw_` ตามด้วยตัวอักษร 43 ตัว สร้างจาก 32 ไบต์ของ `Utilities.getUuid()` สองครั้ง มีความสุ่มประมาณ **244 บิต** (UUID เวอร์ชัน 4 แต่ละตัวสุ่มได้ 122 บิต) เดาไม่ได้ในทางปฏิบัติ
- ชีตเก็บแค่ **SHA-256** ของโทเคนกับส่วนต้น 7 ตัวอักษร คนที่เปิดชีตได้ก็ไม่ได้โทเคนไป
- โทเคนที่ไม่มีอยู่ ถูกเพิกถอน หรือหมดอายุ ได้คำตอบเหมือนกันทุกตัวอักษร (`TOKEN_INVALID`) จึงไม่มีใครรู้ได้ว่าโทเคนไหนเคยมีอยู่จริง
- จำกัดความถี่ต่อโทเคน: อ่าน 120 ครั้ง และเขียน 20 ครั้ง ต่อ 10 นาที
- การเขียนแต่ละครั้งต้องมี `clientId` ถ้าทางลัดส่งคำขอเดิมซ้ำ (เช่น เน็ตหลุดแล้วลองใหม่) ภายใน 6 ชั่วโมง จะไม่ถูกบันทึกซ้ำ
- "ใช้ล่าสุด" ถูกบันทึกลงชีตอย่างมากทุก 45 นาทีต่อโทเคน วิดเจ็ตที่รีเฟรชบ่อยจึงไม่ทำให้ชีตทำงานหนัก
- **ถ้าโทเคนอ่านอย่างเดียวหลุด:** คนอื่นเห็นชื่อและยอดของกระเป๋าที่เลือก กับยอดรวม (หรือแค่ชื่อ ถ้าเปิดซ่อนจำนวนเงิน)
- **ถ้าโทเคนอ่าน + เขียนหลุด:** นอกจากนั้นยังเพิ่มรายการได้ไม่เกิน 20 รายการต่อ 10 นาที เฉพาะกระเป๋าและประเภทที่อนุญาต แก้ไข/ลบ/ดูประวัติไม่ได้ เพิกถอนแล้วหยุดทันที และดูได้ว่าโทเคนเพิ่มอะไรไปบ้างจากคอลัมน์ `Source`
- **โทเคนใน URL:** KWGT ต้องใส่โทเคนไว้ใน URL เพราะ `$wg$` ส่งได้แค่ GET URL อาจถูกเก็บในประวัติหรือ log ของแอปนั้น ให้ใช้โทเคน **อ่านอย่างเดียว** กับ KWGT เสมอ สคริปต์ iPhone, Apple Shortcuts และ HTTP Shortcuts ส่งโทเคนใน body ของ POST ไม่อยู่ใน URL

## 4. iPhone: วิดเจ็ตด้วย Scriptable

### ติดตั้ง

1. ติดตั้ง **Scriptable** (ฟรี) จาก App Store
2. ในแอป Quick Wallet → วิดเจ็ตและทางลัด → โทเคนของคุณ → **ตั้งค่า** → แท็บ **iPhone** → กด **คัดลอกสคริปต์** (ที่อยู่ API และแอปจะถูกเติมให้แล้ว) ไฟล์ต้นฉบับอยู่ที่ `frontend/public/widgets/ios/QuickWallet.scriptable.js`
3. เปิด Scriptable → **+** → วางสคริปต์ → แตะชื่อด้านบน ตั้งชื่อว่า `Quick Wallet`
4. กด **▶** หนึ่งครั้ง วางโทเคนเมื่อถูกถาม (เก็บใน Keychain ของ iOS ไม่ได้เขียนลงไฟล์สคริปต์) แล้วเลือก **ดูตัวอย่างทุกแบบ** เพื่อดูวิดเจ็ตทั้ง 8 แบบ
   - เมนูเดียวกันมี **เปลี่ยนโทเคน** (ใช้หลังกดสร้างใหม่) และ **ล้างแคช**
5. กดค้างที่หน้าจอโฮม → **+** (มุมซ้ายบน) → **Scriptable** → เลือกขนาด → **เพิ่มวิดเจ็ต**
6. กดค้างที่วิดเจ็ต → **แก้ไขวิดเจ็ต** → **Script:** `Quick Wallet` → ใส่ **Parameter** ตามตารางด้านล่าง (ช่อง **When Interacting** ปล่อยค่าเริ่มต้นได้ ลิงก์ที่สคริปต์ตั้งให้ปุ่มและวิดเจ็ตจะถูกใช้แทน)

### Parameter

รูปแบบ `คีย์=ค่า` คั่นด้วย `;` เช่น `layout=medium-grid; lang=th` ถ้าเว้นว่าง จะเลือกแบบตามขนาดวิดเจ็ตเอง (เล็ก = `small-total`, กลาง = `medium-grid`, ใหญ่ = `large`)

| คีย์ | ค่า | ความหมาย |
|---|---|---|
| `layout` | `small-total` | ยอดรวมตัวใหญ่ + เวลาอัปเดต แตะ = ฟอร์มรายจ่าย |
| | `small-wallets` | ยอดรวม + กระเป๋า 3 ใบ |
| | `medium-grid` | ยอดรวม + กระเป๋า 4 ใบ (2 คอลัมน์) + ปุ่ม **− จ่าย / + รับ / ⇄ โอน** (แตะแยกกันได้) |
| | `medium-list` | ยอดรวม + รายการกระเป๋า 5 ใบ |
| | `large` | ยอดรวม + กระเป๋าสูงสุด 8 ใบ + ปุ่มทั้ง 3 |
| `wallets` | `KBank,เงินสด` หรือ id | เลือกและเรียงกระเป๋าจากชุดที่โทเคนแสดง (ชื่อหรือ id คั่นด้วย `,`) |
| `hide` | `1` | ซ่อนจำนวนเงินบนวิดเจ็ตนี้ (แสดง `•••`) |
| `lang` | `th` / `en` | ภาษาบนวิดเจ็ต (ค่าเริ่มต้นตามภาษาเครื่อง) |
| `buttons` | `shortcut` | ปุ่มรันทางลัด Apple Shortcuts แทนการเปิดฟอร์มใน Safari |

ตัวอย่าง

```
layout=medium-grid; lang=th
layout=medium-list; wallets=KBank,บัตรเครดิต,เงินสด
layout=large; hide=1
layout=medium-grid; buttons=shortcut
```

### หน้าจอล็อก

กดค้างที่หน้าจอล็อก → **ปรับแต่ง** → หน้าจอล็อก → แตะช่องวิดเจ็ต → **Scriptable** → เลือกขนาด → แตะวิดเจ็ตเพื่อเลือก Script `Quick Wallet`

- **แถวเดียว (Inline)** ยอดรวมแบบย่อ เช่น `QW 48k · ต้นทุนหุ้น`
- **สี่เหลี่ยม (Rectangular)** ยอดรวม + กระเป๋า 2 ใบ
- **วงกลม (Circular)** ยอดรวมแบบย่อ

แบบหน้าจอล็อกแตะได้จุดเดียว (เปิดฟอร์มรายจ่าย หรือรันทางลัดรายจ่าย ถ้าตั้ง `buttons=shortcut`) วิดเจ็ตขนาดเล็กก็แตะได้จุดเดียวเช่นกัน มีแค่ขนาดกลางและใหญ่ที่มีปุ่มแยก 3 ปุ่ม

### ปุ่มทำอะไร และเมื่อไรควรเปลี่ยนเป็น `buttons=shortcut`

- **ค่าเริ่มต้น (เปิดฟอร์ม):** ใช้ได้ทันทีโดยไม่ต้องตั้งค่าเพิ่ม เปิดฟอร์มของแอปใน **Safari** (เข้าสู่ระบบใน Safari ครั้งแรกหนึ่งครั้ง) เหมาะเมื่อมีแค่โทเคนอ่านอย่างเดียว หรือยังไม่ได้สร้างทางลัด
- **`buttons=shortcut`:** ปุ่มจะรันทางลัดชื่อ `Quick Wallet: รายจ่าย`, `Quick Wallet: รายรับ`, `Quick Wallet: โอน` (ข้อ 5) ซึ่งถามจำนวนเงินแล้วบันทึกเลย แอป Shortcuts จะเด้งขึ้นมาสั้น ๆ แต่ไม่ต้องเปิด Safari เปลี่ยนเมื่อสร้างทางลัดครบแล้ว **ชื่อทางลัดต้องตรงทุกตัวอักษร** รวมช่องว่างหลัง `:`

### ข้อมูลเก่าและออฟไลน์

ทุกครั้งที่ดึงข้อมูลสำเร็จ สคริปต์เก็บคำตอบล่าสุดไว้ในเครื่อง ถ้าออฟไลน์หรือเซิร์ฟเวอร์ตอบผิดพลาด วิดเจ็ตจะแสดงตัวเลขล่าสุดพร้อมป้าย **ข้อมูลเก่า** ไม่ว่างเปล่า ถ้ายังไม่เคยดึงข้อมูลได้เลย จะแสดงข้อความชวนตั้งค่า

## 5. iPhone: เพิ่มรายการด่วนด้วย Apple Shortcuts

ต้องใช้โทเคน **อ่าน + เขียน** ค่าที่ต้องใช้ (URL, โทเคน, id ของกระเป๋า) อยู่ในแอป: วิดเจ็ตและทางลัด → ตั้งค่า → iPhone → ขั้นตอน "เพิ่มด่วนด้วย Apple Shortcuts"

> ชื่อ action ในวงเล็บเป็นชื่อภาษาอังกฤษ ถ้าเครื่องตั้งเป็นภาษาไทยอาจแปลต่างไปเล็กน้อย ใช้ช่องค้นหา action ด้วยคำภาษาอังกฤษได้

### ทางลัด "Quick Wallet: รายจ่าย"

1. เปิดแอป **คำสั่งลัด (Shortcuts)** → **+** → ตั้งชื่อ **`Quick Wallet: รายจ่าย`** (ต้องตรงทุกตัวอักษร ถ้าจะใช้ `buttons=shortcut`)
2. **ขอรับข้อมูลเข้า (Ask for Input)** → ชนิด **ตัวเลข (Number)** → คำถาม `จำนวนเงิน`
3. **พจนานุกรม (Dictionary)** → เพิ่มทีละแถว: คีย์ = ชื่อกระเป๋า, ค่า (ข้อความ) = id ของกระเป๋า (คัดลอกจากแอป) ใส่เฉพาะกระเป๋าที่โทเคนนี้เขียนได้
   - (ทางเลือก แบบดึงรายการจากเซิร์ฟเวอร์: **รับเนื้อหาของ URL** แบบ POST JSON `{"action":"widget.options","method":"GET","token":"qw_…"}` → **รับค่าในพจนานุกรม** `writeWallets` ได้ชื่อกระเป๋า แต่ยังต้องจับคู่ชื่อกับ id อยู่ดี การใช้พจนานุกรมแบบคงที่ในข้อนี้จึงง่ายกว่า)
4. **เลือกจากรายการ (Choose from List)** → รายการ = **พจนานุกรม** (จะแสดงชื่อกระเป๋า) → คำถาม `กระเป๋าเงิน`
5. **รับค่าสำหรับคีย์ในพจนานุกรม (Get Dictionary Value)** → รับ **ค่า** ของ **รายการที่เลือก (Chosen Item)** ใน **พจนานุกรม** → ได้ id ของกระเป๋า
6. **ขอรับข้อมูลเข้า (Ask for Input)** → ชนิด **ข้อความ** → คำถาม `โน้ต (เว้นว่างได้)` → แตะลูกศรขยาย ปิด **ต้องการข้อมูล (Require Input)** ถ้ามีตัวเลือกนี้
7. (ไม่บังคับ) หมวดหมู่: **รายการ (List)** ใส่ชื่อหมวดหมู่ที่มีในแอป (เช่น `Dining`, `Transport`, `Other`) → **เลือกจากรายการ** ถ้าไม่ส่งหมวดหมู่ เซิร์ฟเวอร์ใช้ `Other` (หรือหมวดแรกในรายการ ถ้าไม่มี Other) ชื่อหมวดหมู่ที่ไม่มีอยู่จริงจะถูกปฏิเสธ
8. **วันที่ปัจจุบัน (Current Date)** → **จัดรูปแบบวันที่ (Format Date)** → รูปแบบ **กำหนดเอง** `yyyy-MM-dd` (ทำให้วันที่ตรงกับเขตเวลาของโทรศัพท์)
9. รหัสกันบันทึกซ้ำ (`clientId`):
   - **จัดรูปแบบวันที่** อีกครั้ง → วันที่ปัจจุบัน → กำหนดเอง `yyyyMMddHHmmss`
   - **ตัวเลขสุ่ม (Random Number)** ระหว่าง `100000` ถึง `999999`
   - **ข้อความ (Text)** → `sc-` ตามด้วยตัวแปรวันที่จากข้อนี้ ขีด `-` และตัวเลขสุ่ม เช่น `sc-20261105093012-482913`
10. **รับเนื้อหาของ URL (Get Contents of URL)**
    - URL: ที่อยู่ Apps Script ที่ลงท้ายด้วย `/exec` (คัดลอกจากแอป)
    - แตะ **แสดงเพิ่มเติม** → วิธี **POST** → เนื้อหาคำขอ **JSON** → เพิ่มฟิลด์ (ชนิดข้อความ ยกเว้น amount เป็นตัวเลข)

      | คีย์ | ค่า |
      |---|---|
      | `action` | `widget.add` |
      | `token` | โทเคนของคุณ `qw_…` |
      | `type` | `expense` |
      | `amount` | (ตัวเลข) ข้อมูลที่ป้อน จากข้อ 2 |
      | `walletId` | ค่าในพจนานุกรม จากข้อ 5 |
      | `note` | ข้อมูลที่ป้อน จากข้อ 6 |
      | `category` | (ถ้าทำข้อ 7) รายการที่เลือก |
      | `date` | วันที่ที่จัดรูปแบบ จากข้อ 8 |
      | `clientId` | ข้อความ จากข้อ 9 |

    - ไม่ต้องตั้งค่าการเปลี่ยนเส้นทาง: Apps Script ตอบด้วย 302 redirect และ Shortcuts ตามให้เอง คำขอถูกบันทึกไปแล้วตั้งแต่ก่อน redirect
11. **รับค่าสำหรับคีย์ในพจนานุกรม** → คีย์ `error` จาก **เนื้อหาของ URL**
12. **ถ้า (If)** ค่าในพจนานุกรม **มีค่าใด ๆ (has any value)**
    - **แสดงการแจ้งเตือน (Show Notification)** → `บันทึกไม่สำเร็จ: ` + ค่าในพจนานุกรม
13. **มิฉะนั้น (Otherwise)**
    - **รับค่าสำหรับคีย์ในพจนานุกรม** → คีย์ `warning` จาก **เนื้อหาของ URL**
    - **ถ้า** ค่านั้น **มีค่าใด ๆ** → **แสดงการแจ้งเตือน** `⚠️ บันทึก ฿` + ข้อมูลที่ป้อน + ` แล้ว แต่ยอดกระเป๋าติดลบ`
    - **มิฉะนั้น** → **แสดงการแจ้งเตือน** `✅ บันทึก ฿` + ข้อมูลที่ป้อน + ` แล้ว`
    - (ไม่บังคับ) ยอดใหม่: รับค่า `newBalances` → รับค่าคีย์ = id กระเป๋า (จากข้อ 5) → รับค่า `text` แล้วใส่ในข้อความแจ้งเตือน
14. **ปิดถ้า (End If)** ทั้งสองชั้น แล้วกด **เสร็จสิ้น**

### "Quick Wallet: รายรับ"

ทำซ้ำทางลัดรายจ่าย (กดค้าง → ทำสำเนา) แล้วเปลี่ยนชื่อเป็น **`Quick Wallet: รายรับ`** และเปลี่ยน `type` เป็น `income`

### "Quick Wallet: โอน"

ทำสำเนาทางลัดรายจ่าย ตั้งชื่อ **`Quick Wallet: โอน`** แล้ว

- เปลี่ยน `type` เป็น `transfer`
- หลังข้อ 5 เพิ่ม **เลือกจากรายการ** อีกครั้ง (คำถาม `ไปยังกระเป๋า`) และ **รับค่าในพจนานุกรม** อีกครั้ง → ได้ id ปลายทาง
- เพิ่มฟิลด์ `toWalletId` = id ปลายทาง ลบข้อ 7 และฟิลด์ `category` ออก (การโอนไม่มีหมวดหมู่)
- กระเป๋าทั้งสองใบต้องอยู่ในรายการ "กระเป๋าที่เพิ่มรายการได้" ของโทเคน

### วางทางลัดให้กดง่าย

- **หน้าจอโฮม:** ในทางลัด แตะ ⓘ (หรือชื่อด้านบน) → **เพิ่มไปยังหน้าจอโฮม**
- **ปุ่มแอ็คชั่น (Action Button)** (iPhone 15 Pro ขึ้นไป): ตั้งค่า → ปุ่มแอ็คชั่น → **คำสั่งลัด** → เลือกทางลัด
- **แตะด้านหลัง (Back Tap):** ตั้งค่า → การช่วยการเข้าถึง → สัมผัส → **แตะด้านหลัง** → แตะสองครั้ง/สามครั้ง → เลือกทางลัด
- **ปุ่มบนวิดเจ็ต:** ใส่ `buttons=shortcut` ใน Parameter ของวิดเจ็ต (ข้อ 4)

## 6. Android: วิดเจ็ตด้วย KWGT

### ติดตั้ง

1. ติดตั้ง **KWGT Kustom Widget Maker** และซื้อ **KWGT Pro Key** (จำเป็นสำหรับการโหลดข้อมูลจาก URL และบันทึกวิดเจ็ตที่สร้างเอง)
2. กดค้างที่หน้าจอโฮม → **วิดเจ็ต** → **KWGT** → เลือกขนาด (เช่น 2×2 สำหรับเล็ก 4×2 สำหรับกลาง 4×4 สำหรับใหญ่) → แตะวิดเจ็ตว่างเพื่อเปิดตัวแก้ไข → **สร้างใหม่ (Create)**
3. แท็บ **Globals** → **+** → **Text** → ตั้งชื่อ **`url`** → ค่า = URL อ่านข้อมูลที่คัดลอกจากแอป (ขั้นตอน Android ข้อ 2) รูปแบบ

   ```
   https://script.google.com/macros/s/…/exec?action=widget&token=qw_…&lang=th
   ```

   ใช้โทเคน **อ่านอย่างเดียว** เท่านั้น

> **ยังไม่ได้ทดสอบ:** ยังไม่ได้ยืนยันว่า KWGT ตาม **302 redirect** ที่ Apps Script ตอบกลับทุกครั้งหรือไม่ (เบราว์เซอร์และแอปส่วนใหญ่ตามให้เอง) ถ้าวิดเจ็ตว่างเปล่า ดู [วิดเจ็ตว่างเปล่า](#วิดเจ็ต-kwgt-ว่างเปล่า)

### สูตร

เพิ่ม **Text** แล้วแตะช่อง Text → ไอคอนสูตร → วางสูตร (คัดลอกได้จากแอปทุกสูตร)

| แสดง | สูตร |
|---|---|
| ยอดรวมเต็ม | `$wg(gv(url), json, .flat.total)$` |
| ยอดรวมย่อ (48k) | `$wg(gv(url), json, .flat.totalShort)$` |
| ป้าย "รวม (ต้นทุนหุ้น)" (ว่างถ้าไม่มีหุ้น) | `$wg(gv(url), json, .flat.totalNote)$` |
| เวลาอัปเดต | `$wg(gv(url), json, .flat.updated)$` |
| ชื่อกระเป๋าที่ 1 | `$wg(gv(url), json, .flat.w1name)$` |
| ยอดกระเป๋าที่ 1 | `$wg(gv(url), json, .flat.w1text)$` |
| ยอดย่อกระเป๋าที่ 1 | `$wg(gv(url), json, .flat.w1short)$` |
| สีของยอด (ติดลบ = แดง) | `$if(wg(gv(url), json, .flat.w1neg) = 1, #FFE5484D, #FFFFFFFF)$` |

เปลี่ยน `w1` เป็น `w2` … `w8` สำหรับกระเป๋าใบถัดไป (ช่องที่ไม่มีกระเป๋าจะเป็นข้อความว่าง ไม่ error) ใช้สูตรสีที่ **Paint → Color** ของ Text ยอดเงิน (แตะไอคอนสูตรข้างช่องสี)

แนะนำให้วาง "ยอดรวม" กับ "รวม (ต้นทุนหุ้น)" ไว้คู่กันในทุกแบบ ป้ายจะว่างเองเมื่อไม่มีหุ้น

### แบบวิดเจ็ต 3 แบบ (ให้เหมือนฝั่ง iPhone)

- **เล็ก (2×2):** Stack แนวตั้ง: ป้าย `totalNote` (ตัวเล็ก) → `total` (ตัวใหญ่) → `updated` (ตัวเล็ก) แตะทั้งวิดเจ็ต = ลิงก์รายจ่าย
- **กลาง (4×2):** ด้านบน `totalNote` + `total` ด้านล่างเป็น Grid 2×2 ของ `wNname` + `wNshort` (N = 1–4) แถวล่างสุด 3 ปุ่ม **− จ่าย / + รับ / ⇄ โอน**
- **ใหญ่ (4×4):** `totalNote` + `total` + `updated` แล้วรายการกระเป๋า 1–8 (ชื่อชิดซ้าย ยอดชิดขวา ใช้สูตรสี) และ 3 ปุ่มด้านล่าง

### ปุ่ม (Touch actions)

เลือก Shape หรือ Text ที่จะเป็นปุ่ม → แท็บ **Touch** → **+** → Action **Open Link** → วางลิงก์จากแอป (ขั้นตอน Android ข้อ 4)

```
https://แอปของคุณ/?quick=expense
https://แอปของคุณ/?quick=income
https://แอปของคุณ/?quick=transfer
```

ถ้ามี HTTP Shortcuts (ข้อ 7) ตั้งปุ่มเป็น **Launch Shortcut** → HTTP Shortcuts → ทางลัดที่สร้างไว้แทนได้ จะบันทึกโดยไม่ต้องเปิดแอป

### ทำไมไม่มีไฟล์ preset `.kwgt` ให้

ไฟล์ `.kwgt` เป็นรูปแบบภายในของ KWGT ที่ไม่มีเอกสารเปิดเผย และสร้างหรือทดสอบนอกแอป KWGT ไม่ได้ ไฟล์ที่สร้างเดาเอาอาจเปิดไม่ขึ้นหรือพังในเวอร์ชันถัดไป จึงให้เป็นขั้นตอนและสูตรแทน เมื่อสร้างเสร็จแล้ว คุณ **ส่งออก (Export)** preset เก็บไว้เองได้จากเมนูของ KWGT (อย่าแชร์ไฟล์นั้น เพราะมีโทเคนอยู่ใน global `url`)

### รอบรีเฟรช

KWGT ดึงข้อมูลจาก `$wg$` ตามรอบของตัวเอง (โดยปกติราว 15–60 นาที ปรับได้ในการตั้งค่าของ KWGT ส่วน Advanced/การอัปเดต ขึ้นกับเวอร์ชัน) Android อาจหน่วงเพิ่มเมื่อเปิดโหมดประหยัดแบตเตอรี่

## 7. Android: เพิ่มรายการด่วนด้วย HTTP Shortcuts

ใช้แอป **HTTP Shortcuts** (ฟรี โอเพนซอร์ส จาก Google Play หรือ F-Droid) กับโทเคน **อ่าน + เขียน**

### ตัวแปร (สร้างครั้งเดียว ใช้ได้ทุกทางลัด)

เมนู ⋮ → **Variables** → **+**

| ชื่อ | ชนิด | ตั้งค่า |
|---|---|---|
| `amount` | **Number Input** | ข้อความ `จำนวนเงิน` |
| `wallet` | **Select** | เพิ่มตัวเลือกทีละใบ: Label = ชื่อกระเป๋า, Value = id ของกระเป๋า (คัดลอกจากแอป) |
| `toWallet` | **Select** | (สำหรับการโอน) เหมือน `wallet` |
| `note` | **Text Input** | ข้อความ `โน้ต (เว้นว่างได้)` |
| `uuid` | **UUID** | ถ้าเวอร์ชันของคุณไม่มีชนิด UUID ให้ใช้ **Timestamp** แทน (ต้องได้ค่าใหม่ทุกครั้งที่รัน) |

### ทางลัด "Add expense / เพิ่มรายจ่าย"

1. หน้าหลัก → **+** → **Regular Shortcut** → ชื่อ `เพิ่มรายจ่าย`
2. **Basic Request Settings:** Method **POST**, URL = ที่อยู่ Apps Script ลงท้ายด้วย `/exec` (คัดลอกจากแอป)
3. **Request Body / Parameters:** ชนิด **Custom Text**, Content Type `text/plain;charset=utf-8` แล้ววาง body ที่คัดลอกจากแอป (ขั้นตอน Android ข้อ 6)

   ```json
   {
     "action": "widget.add",
     "token": "qw_…",
     "type": "expense",
     "amount": "{amount}",
     "walletId": "{wallet}",
     "note": "{note}",
     "clientId": "{uuid}"
   }
   ```

   ลบ `{amount}`, `{wallet}`, `{note}`, `{uuid}` ออกทีละตัว แล้วแตะปุ่ม **{ }** (แทรกตัวแปร) เพื่อใส่ตัวแปรชื่อเดียวกันแทน ต้องคงเครื่องหมาย `"` ไว้รอบตัวแปร ตามตัวอย่าง (เซิร์ฟเวอร์รับ amount ที่เป็นข้อความได้)
4. **Advanced Technical Settings:** เปิด **Follow Redirects** ไว้ (ค่าเริ่มต้น) เพราะ Apps Script ตอบด้วย 302 เสมอ
5. **Response Handling:** ชนิดผลลัพธ์ **Toast** ถ้าต้องการข้อความอ่านง่าย ให้ใช้ **Scripting → Run after success** (โค้ดนี้ยังไม่ได้ทดสอบกับแอปจริง)

   ```js
   const r = JSON.parse(response.body);
   if (!r.ok) {
     showToast('บันทึกไม่สำเร็จ: ' + r.error);
   } else if (r.warning === 'overdraft') {
     showToast('⚠️ บันทึกแล้ว แต่ยอดกระเป๋าติดลบ');
   } else {
     showToast('✅ บันทึกแล้ว');
   }
   ```

   และตั้ง Response Handling เป็น **Do nothing** เมื่อใช้สคริปต์นี้
6. บันทึก

ทำสำเนาสำหรับ **เพิ่มรายรับ** (`"type": "income"`) และ **โอน** (`"type": "transfer"`, เพิ่ม `"toWalletId": "{toWallet}"`, ไม่มีหมวดหมู่)

ส่งหมวดหมู่ได้ด้วย `"category": "Dining"` (หรือตัวแปร Select ของหมวดหมู่) ถ้าไม่ส่ง เซิร์ฟเวอร์ใช้ `Other`

### วางบนหน้าจอโฮม

กดค้างที่ทางลัดใน HTTP Shortcuts → **Place on Home Screen** หรือเพิ่ม **วิดเจ็ต** ของ HTTP Shortcuts ผ่านเมนูวิดเจ็ตของ Android

## 8. ลิงก์เปิดฟอร์มในแอป และทางลัดบนไอคอนแอป

- `?quick=expense` / `?quick=income` / `?quick=transfer` เปิดฟอร์มเพิ่มรายการพร้อมเลือกประเภท
- เพิ่ม `&wallet=<id>` เพื่อเลือกกระเป๋า และ `&to=<id>` สำหรับปลายทางของการโอน (กระเป๋าที่ถูกเก็บเข้าคลังหรือลบไปแล้วจะถูกข้าม)
- ถ้ายังไม่เข้าสู่ระบบ แอปจะให้เข้าสู่ระบบก่อน แล้วเปิดฟอร์ม
- พารามิเตอร์ถูกลบออกจากแถบที่อยู่ทันทีที่อ่าน รีเฟรชหน้าแล้วฟอร์มจะไม่เปิดซ้ำ
- **Android:** หลังติดตั้งแอปจาก Chrome กดค้างที่ไอคอนแอปจะมี **Expense / Income / Transfer** (จากไฟล์ `manifest.webmanifest`)
- **iPhone:** iOS ไม่รองรับทางลัดบนไอคอนเว็บแอป ใช้ Apple Shortcuts แทน

## 9. แก้ปัญหา

### วิดเจ็ตขึ้น "แตะเพื่อตั้งค่า" หรือ TOKEN_INVALID

- โทเคนผิด ถูกเพิกถอน หมดอายุ หรือถูกสร้างใหม่ (โทเคนเก่าใช้ไม่ได้แล้ว) เซิร์ฟเวอร์ตอบเหมือนกันทุกกรณีโดยตั้งใจ ดูสถานะได้ในรายการโทเคนในแอป
- iPhone: เปิดสคริปต์ใน Scriptable → ▶ → **เปลี่ยนโทเคน**
- Android: แก้ค่า global `url` ใน KWGT และโทเคนใน body ของ HTTP Shortcuts

### ได้หน้า HTML หรือ "ต้องลงชื่อเข้าใช้ Google" แทน JSON

การตั้งค่า deploy ไม่ใช่ **ทุกคน (Anyone)** หรือ URL เป็นของ deployment เก่า ดู [ข้อ 2](#2-ติดตั้งฝั่งเซิร์ฟเวอร์-codegs) ข้อ 3–4

### แอปแจ้ง "ต้องอัปเดต Code.gs"

เซิร์ฟเวอร์ยังเป็นเวอร์ชันเก่า วาง Code.gs ใหม่ แล้ว deploy **เวอร์ชันใหม่** ของ deployment เดิม และรัน `setup()`

### วิดเจ็ตแสดงป้าย "ข้อมูลเก่า"

ดึงข้อมูลไม่ได้ในรอบล่าสุด (ออฟไลน์ เซิร์ฟเวอร์ช้า หรือเกินขีดจำกัดความถี่) ตัวเลขที่เห็นคือชุดล่าสุดที่ดึงสำเร็จ รอรอบถัดไป หรือเปิดสคริปต์ใน Scriptable แล้วกด ▶ เพื่อดึงใหม่ ถ้าค้างนาน ลองเปิด URL อ่านข้อมูลในเบราว์เซอร์เพื่อดูข้อความผิดพลาด

### วิดเจ็ต KWGT ว่างเปล่า

1. คัดลอกค่า global `url` ไปเปิดใน Chrome บนโทรศัพท์ ต้องเห็น JSON ที่ขึ้นต้นด้วย `{"updatedAt":` และมี `"ok":true`
   - ถ้าเห็น `"ok":false` อ่านค่า `code` แล้วดูตาราง[รหัสข้อผิดพลาด](#รหัสข้อผิดพลาด)
   - ถ้าเห็นหน้า HTML หรือหน้าลงชื่อเข้าใช้ Google → ดูหัวข้อ "ได้หน้า HTML" ด้านบน
2. ถ้า Chrome แสดง JSON ปกติแต่ KWGT ว่าง สาเหตุที่เป็นไปได้คือ KWGT ไม่ตาม 302 redirect (ยังไม่ได้ทดสอบ) หรือยังไม่ถึงรอบรีเฟรช
   - ลองใส่ path ในเครื่องหมายคำพูด: `$wg(gv(url), json, ".flat.total")$`
   - ลองสูตรดิบ `$wg(gv(url), txt)$` ถ้าได้ข้อความ JSON แสดงว่าดึงได้ ปัญหาอยู่ที่ path ถ้าว่างหรือได้ HTML แสดงว่า KWGT ไม่ตาม redirect
   - บังคับรีเฟรช: ลบวิดเจ็ตแล้วเพิ่มใหม่ หรือเพิ่ม Touch action **Kustom Action → Refresh** ไว้ที่วิดเจ็ต
3. ถ้ายืนยันได้ว่า KWGT ไม่ตาม redirect: ใช้ HTTP Shortcuts หรือ Tasker ดึง URL แล้วส่งค่าเข้า KWGT แทน (ขั้นสูง) และแจ้งปัญหานี้เพื่อหาทางอื่นร่วมกัน

### Shortcuts หรือ HTTP Shortcuts ได้ "Moved Temporarily" หรือ 302

ต้องเปิดการตาม redirect (HTTP Shortcuts: Advanced → **Follow Redirects**; Apple Shortcuts ตามให้เองเสมอ) รายการถูกบันทึกแล้วตั้งแต่คำขอแรก การส่งซ้ำด้วย `clientId` เดิมจะไม่บันทึกซ้ำ

### บันทึกไม่สำเร็จ

- `READ_ONLY_TOKEN` ใช้โทเคนอ่านอย่างเดียว → สร้างโทเคนอ่าน + เขียน
- `WALLET_NOT_ALLOWED` กระเป๋าไม่อยู่ในรายการ "กระเป๋าที่เพิ่มรายการได้" ของโทเคน (การโอนต้องมีทั้งสองใบ) แก้ได้ที่ แก้ไขโทเคน
- `ACTION_NOT_ALLOWED` โทเคนไม่ได้อนุญาตประเภทนี้
- `BAD_CATEGORY` ชื่อหมวดหมู่ไม่ตรงกับในแอป (ไม่สนตัวพิมพ์เล็กใหญ่)
- `BAD_AMOUNT` ต้องมากกว่า 0 ไม่เกิน 10,000,000 และทศนิยมไม่เกิน 2 ตำแหน่ง
- `BAD_DATE` วันที่ต้องเป็น `yyyy-MM-dd` ล่วงหน้าไม่เกิน 1 วัน และย้อนหลังไม่เกิน 1 ปี
- `RATE_LIMIT` เกิน 20 รายการใน 10 นาที รอสักครู่
- `WRONG_WALLET_MODE` กระเป๋าลงทุนรับได้แค่การโอน

### ได้ `warning: "overdraft"`

รายการถูกบันทึกแล้ว แต่ทำให้กระเป๋าที่ไม่ใช่บัตรเครดิตติดลบ ในแอปจะเตือนก่อนบันทึก แต่ทางลัดเตือนหลังบันทึก ถ้าบันทึกผิด แก้ไขหรือลบรายการได้ในแอป (รายการจากทางลัดมีข้อความ "เพิ่มจาก <ชื่อโทเคน>" ในหน้าแก้ไข)

### โทเคนเคยใช้ได้ แล้วหยุดทำงาน

ตรวจในแอปว่าโทเคนยัง **ใช้งานอยู่** หรือเป็น **หมดอายุ / เพิกถอนแล้ว** ถ้ามีคนกด **สร้างใหม่** โทเคนเก่าจะหยุดทำงานทันที ต้องใส่โทเคนใหม่ทุกที่ ถ้าเพิ่ง deploy ใหม่ด้วย deployment ใหม่ (URL ใหม่) ต้องเปลี่ยน URL ในทุกวิดเจ็ตและทางลัดด้วย

## 10. อ้างอิง: รูปแบบ JSON และรหัสข้อผิดพลาด

คำตอบของ action วิดเจ็ตเป็น JSON แบบแบน (ไม่มีชั้น `data` เหมือน API ของแอป)

### อ่าน: `GET ?action=widget&token=…&lang=th`

หรือ POST body `{"action":"widget","method":"GET","token":"qw_…","query":{"lang":"th"}}` (ไม่ใส่โทเคนใน URL)

```json
{
  "ok": true, "v": 1,
  "updatedAt": "2026-11-05T02:30:00.000Z", "updatedTime": "09:30",
  "currency": "THB", "lang": "th", "totalMode": "all", "hideAmounts": false,
  "total": 40500, "totalText": "฿40,500.00", "totalShort": "41k",
  "totalNote": "รวม (ต้นทุนหุ้น)",
  "wallets": [
    { "id": "…", "name": "KBank", "type": "bank", "credit": false, "investment": false,
      "balance": 32000, "text": "฿32,000.00", "short": "32k", "negative": false }
  ],
  "flat": { "count": "1", "total": "฿40,500.00", "totalShort": "41k",
            "totalNote": "รวม (ต้นทุนหุ้น)", "updated": "09:30",
            "w1name": "KBank", "w1text": "฿32,000.00", "w1short": "32k", "w1neg": "0",
            "w2name": "", "…": "…ถึง w8" }
}
```

- ตัวเลขแปลงเป็นสกุลเงินแสดงผลตามที่ตั้งในแอปแล้ว และจัดรูปแบบด้วยกฎเดียวกับแอป (k/M/B)
- บัตรเครดิตแสดงยอดเป็นค่าติดลบ (`negative: true`)
- `totalNote` ว่างเมื่อไม่มีหุ้นถือ
- เมื่อ `hideAmounts` เป็น `true`: `total` และ `balance` เป็น `null`, ข้อความเป็น `•••`

### ตัวเลือก: `?action=widget.options&token=…`

```json
{ "ok": true, "v": 1, "scope": "readwrite", "actions": ["expense", "transfer"],
  "wallets": [ { "id": "…", "name": "KBank", "type": "bank", "credit": false,
                 "investment": false, "show": true, "write": true } ],
  "writeWallets": ["KBank"], "categories": ["Dining", "Other"], "today": "2026-11-05" }
```

แสดงเฉพาะกระเป๋าที่โทเคนนี้แสดงหรือเขียนได้ ไม่มีวันแสดงกระเป๋าทั้งหมด

### เพิ่มรายการ: `POST` (โทเคนอ่าน + เขียนเท่านั้น)

```json
{ "action": "widget.add", "token": "qw_…", "type": "expense", "amount": 120,
  "walletId": "…", "toWalletId": "…(เฉพาะ transfer)", "category": "Dining",
  "note": "ข้าวกลางวัน", "date": "2026-11-05", "clientId": "sc-20261105093012-482913" }
```

คำตอบ

```json
{ "ok": true, "v": 1, "id": "…", "duplicate": false, "type": "expense", "amount": 120,
  "date": "2026-11-05",
  "newBalances": { "<walletId>": { "name": "KBank", "balance": 31880, "text": "฿31,880.00" } },
  "warning": "overdraft" }
```

`warning` มีเฉพาะเมื่อกระเป๋าที่ไม่ใช่บัตรเครดิตติดลบ `duplicate: true` เมื่อเป็นการส่งซ้ำด้วย `clientId` เดิม (ไม่ได้บันทึกเพิ่ม) `clientId` ยาว 8–64 ตัว ใช้ได้ `A-Z a-z 0-9 . _ : -`

### รหัสข้อผิดพลาด

คำตอบผิดพลาด: `{ "ok": false, "v": 1, "status": 403, "code": "…", "error": "…" }`

| code | ความหมาย |
|---|---|
| `TOKEN_INVALID` | โทเคนไม่ถูกต้อง ไม่มีอยู่ ถูกเพิกถอน หรือหมดอายุ (ตอบเหมือนกันทุกกรณี) |
| `READ_ONLY_TOKEN` | โทเคนอ่านอย่างเดียวพยายามเขียน |
| `ACTION_NOT_ALLOWED` | ประเภทรายการไม่ได้รับอนุญาตสำหรับโทเคนนี้ |
| `WALLET_NOT_ALLOWED` | กระเป๋าไม่อยู่ในรายการที่โทเคนเขียนได้ |
| `SAME_WALLET` | โอนเข้ากระเป๋าเดียวกัน |
| `BAD_TYPE` `BAD_AMOUNT` `BAD_DATE` `BAD_CATEGORY` `BAD_NOTE` `BAD_CLIENT_ID` | ข้อมูลไม่ถูกต้อง (ดูข้อความ `error`) |
| `WRONG_WALLET_MODE` | กระเป๋าลงทุนรับได้แค่การโอน |
| `METHOD_NOT_ALLOWED` | ส่ง `widget.add` ด้วย GET (ต้องเป็น POST) |
| `RATE_LIMIT` | เกินขีดจำกัดความถี่ (อ่าน 120 / เขียน 20 ครั้งต่อ 10 นาทีต่อโทเคน) |
| `BUSY` | ชีตกำลังถูกใช้งาน ลองใหม่อีกครั้ง |
| `SERVER_ERROR` | ข้อผิดพลาดภายในเซิร์ฟเวอร์ (รายละเอียดอยู่ใน log ของ Apps Script ไม่ส่งออกมา) |
